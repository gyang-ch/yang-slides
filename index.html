Phyto-Vision

A Reproducible Workflow for the Computational Excavation of Global Botanical Iconography

Guang Yang

Research Context

Botanical archives as visual systems

  • Botanical knowledge historically circulated through image–text assemblages
  • Illustrations functioned as tools of:
    • taxonomy
    • classification
    • imperial knowledge-making
  • European botanical illustration emphasised:
    • standardisation
    • morphological comparison
    • isolated specimens
  • Parallel traditions also existed:
    • Chinese Bencao
    • Japanese illustrated herbals
    • medicinal manuscripts

Emphasise that this project is not only technical, but also historical and epistemological.

Project Aim

What is Phyto-Vision?

Phyto-Vision is a reproducible computational workflow for:

  • metadata normalisation
  • archival deduplication
  • automated botanical illustration extraction
  • visual similarity analysis

Goal

Transform heterogeneous digitised botanical pages into a structured, machine-readable visual corpus.

Metadata and Deduplication

Building interoperable archives

  • Metadata schema adapted from the ZuantuSet workflow
  • Descriptive fields normalised into machine-readable formats
  • Duplicate editions identified through image collation techniques
  • Supports:
    • longitudinal comparison
    • cross-cultural analysis
    • scalable archival integration

Iconographic Extraction

YOLOv11 object detection

  • Seed corpus:
    • 781 manually annotated illustrations
  • Sources included:
    • Library of Congress
    • Bibliothèque nationale de France
    • Royal Horticultural Society
    • National Archives of Japan
    • University of Tokyo Library

Data augmentation

  • horizontal flipping
  • random cropping
  • noise injection

Expanded training set: 1,875 images

Visual Embedding Analysis

Beyond detection

After extraction:

  • Illustrations converted into embeddings using:
    • DINOv2 ViT-B/14
  • Similarity measured using:
    • cosine similarity
  • Clustering performed with:
    • HDBSCAN

Enables

  • similarity retrieval
  • visual grouping
  • cross-cultural comparison
  • unsupervised pattern discovery
